# Calculator

A responsive calculator built with React and Vite. It supports basic arithmetic operations, percentages, decimal values, calculation results, and calculation history.

## Features

- Addition, subtraction, multiplication, and division
- Decimal calculations
- Percentage calculations
- Clear button
- Calculation history sidebar
- Click previous calculations to reuse them
- Division-by-zero and invalid-expression handling
- Responsive desktop, tablet, and mobile layout

## Technologies

- React
- Vite
- JavaScript
- Math.js
- CSS
